# 主实验对照表（M4：4 臂 × 5 策略 × 5 种子）

> 全部结果为确定性仿真结果，非真实设备测量数据。参数取自公开文献与行业公开区间的占位取值，待标定后更新。

## 报告口径（SPEC §10.6 固定定义）

**SLA 达标率定义**：1 − 延迟任务数 / 总任务数；分母只含 S2/S3 规划任务（S1 在线推理已并入 IT_base，不重复计算）；延迟 = 完成时刻 > deadline_h。
**关键负荷定义（韧性评估用）**：critical_it_fraction = 0.60 × IT_base（设施侧 IT 口径，母线侧 × PUE）；判据 shed_c ≤ ε_shed = 1e-9 MW。
**降级策略定义（韧性评估用）**：故障模式四级字典序（关键削减 → 非关键削减 → 供热缺口 → 化学体系偏好），第一级 gap = 0 求至证明最优；T_island 是**降级策略下**的续航，不是最优策略下的续航。
**等效循环次数口径**：Σ_t max(0, soc(t) − soc(t+1))（SOC 掉幅口径，不除以 2）。
**LCOE 口径**：(年化运营成本 + 储能年化成本) / 年服务电量 Σ IT_load·Δt；运营成本含购电 − 售电 − 工业供热收入 + 锅炉燃料成本 + 弃电惩罚，**不含 SLA 惩罚**；储能年化成本含 CRF×投资 + 运维 + **替换成本**（CRF 由折现率 0.06 与项目寿命 20 年现算）。
**碳账口径**：电网因子（区域常数，生成数据无时变幅度）+ 锅炉燃气 − 工业供热替代；储能制造碳按项目寿命摊销计入净碳；**碳资产不折算收入计入经济性指标**。

## 阅读注记（比较前必读）

- **路径**：低保真代表周（5×168 h，权重 0.18/0.16/0.22/0.22/0.22，覆盖四季 + 极端低温周 W-WINX；BT2 裁定，§6.3 要求写明路径选择）。年化 = Σ 周结果 × 权重 × 365/7。
- **f3 / 韧性列不可分辨（NON-DISCRIMINATING）**：低保真 `resilience_gap = NaN`（§4.2）；臂级 T_island/EENS/N-1 列来自 M2.5 场景包（故障调度与策略无关，按臂合并），当前占位数据下孤岛观测**全部右删失**，这些列**不得参与任何排序**，仅作口径披露。
- **绿电匹配率口径**：分母含储能充电、不追溯储能出力来源（solver_info 已声明），**不可跨储能规模直接对比**（A0 与带储能臂的差异主要是口径效应）。
- **S-base 注记**：规则驱动（objective 为 NaN 属契约行为）；其盈余/电网充电只到 soc_ref（BS3 策略约束），弃电随储能容量放大是**内建不对称**，跨策略比较须携带此注记；S-base 的目标值不与其他策略直接比较（量纲不同）。
- **规模归一化**：A1/A2/A3 统一 150 MWh / 45 MW（§6.1），投资额差异只反映化学体系单价；A0 投资为 0。跨臂比较 LCOE 时必须同时给出 `investment_yuan` 与 `net_annual_cost`。
- **BT2-③ 临时结论标记**：`provisional_for_comparison = True` 表示该组存在认证 gap > 2% 的窗口，涉及该组的跨臂对比只能作为临时结论。报告的 gap 一律为**认证 gap**（后端对偶界或夹逼证书），不是可行解自述值。
- **容量衰减列为估算值**（1 年运行口径，§10.1），不进成本侧；零容量体系记 NaN。
- **钠电不预设优势**：本表不给出任何「获胜配置」；结论表述一律为「在参数区间 P 下，配置 C 在指标 M 上更优/更差」。
